# Формулы заголовков

Выбирать по смыслу текущего проекта, не проходить весь список. Факты и условия брать из материалов проекта.

[Призыв] + [действие/результат]
Как + [решить проблему]?
[Что узнаете] + [где / как]
[Результат] + [в срок]
[Польза] + [от кого] + [призыв]
[Что будет разбираться] + [в каком формате]
[Результат действия] + [на интенсиве / марафоне]
[Контраст] + [новое решение]
[Попадание в страх + обещание]
[Что произойдет на марафоне] + [конкретный результат]
[Социальное доказательство / авторитет]
[Результат обучения] + [бонус]

## Живая подача

[Живая реплика] + [конкретный продукт или задача]
[Неожиданный, но честный образ] + [понятный предмет предложения]
[Узнаваемая ситуация клиента] + [следующий шаг]
[Действие] + [полезный материал] + [понятная область применения]

Эти конструкции не требуют сленга. Истории от первого лица, отзывы, числовые результаты и превосходные степени нельзя выдумывать.


## Вход через содержание продукта

[Конкретный выбор: способ А или способ Б] + [где разобраться]
[Узнаваемые техники или задачи] + [собраны в материале]
[Подборка продуктов или инструментов] + [способ получить]
[Повторить видимый образец] + [подтверждённый способ обучения]
[Уместный сегмент] + [конкретная техника или задача] + [формат]
[Личное приглашение к материалу] + [его предметная польза]

Подробные авторские примеры и условия применения — в разделе «Дополнительные углы от Ильвины для книги по макияжу» библиотеки заголовков. Выбирать только подтверждённое содержание текущего продукта; не превращать эти конструкции в обязательный набор для каждой ниши.
