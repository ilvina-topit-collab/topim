# ТОПИМ

Помощник Ильвины для подготовки рекламных текстов по материалам вашего проекта.

## Что умеет

- Изучает сайт, описание или скриншоты посадочной.
- Предлагает сразу перейти к текстам или сначала разобрать аудиторию через короткий JTBD.
- Создаёт заголовки и отдельные совместимые описания.
- Предлагает новые заходы для рекламных тестов и варианты с вашим словом.
- Подбирает быстрые ссылки, их описания и уточнения по преимуществам продукта.

Подходит для обучения, услуг, локального бизнеса и товаров. Не загружает и не запускает кампании. Готовые тексты стоит проверить перед использованием.

## Скачать и установить

[Скачать скилл ТОПИМ](./topim.zip)

1. Скачайте и распакуйте архив.
2. Прикрепите папку `topim` в Codex и отправьте:

> Изучи папку topim, прочитай SKILL.md и связанные материалы. Установи скилл в мою папку личных скиллов, сохранив файлы и структуру. Если ТОПИМ уже установлен, обнови его.

3. Начните новый чат, выберите скилл ТОПИМ и отправьте сайт, текст или скриншоты проекта.

Можно начать так:

> Давай готовить РК. Вот мой проект: …

## Что приложить для точного результата

Описание конкретного продукта, посадочную, условия предложения и материалы об аудитории. Если есть свои удачные объявления, приложите их тоже.
